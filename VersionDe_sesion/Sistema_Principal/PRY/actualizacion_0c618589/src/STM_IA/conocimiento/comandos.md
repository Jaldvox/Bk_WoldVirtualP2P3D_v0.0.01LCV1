# Comandos de la consola LucIA

Comandos disponibles en la sesion interactiva:

- **estado**: muestra bloques, cadena, neuronas, deriva y modelo activo.
- **modelo <nombre>**: cambia el modelo Ollama activo.
- **minar**: mina manualmente las transacciones pendientes.
- **modelos**: lista los modelos gratuitos disponibles.
- **escuchar / voz / hablar**: dicta el prompt por microfono (STT).
- **saber <tema>**: consulta la base de conocimiento especifico.
- **salir**: cierra la sesion, mina el bloque final y sube a IPFS.
