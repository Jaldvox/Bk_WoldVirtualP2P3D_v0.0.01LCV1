# Blockchain BKSVCB y consenso PoNL

La blockchain **BKSVCB** es el libro mayor inmutable de LucIA:

- Consenso **PoNL (Proof of Neural Learning)**: cada bloque registra
  gradientes hebbianos y estado emocional del turno.
- Hashing doble **SHA-256** con raiz de **Merkle** por bloque.
- **Minado automatico cada 3 turnos** de conversacion.
- API REST en `http://127.0.0.1:8545` con rutas
  `/status`, `/blocks`, `/mine` y `/transform`.
- Al cerrar sesion, el ledger y los pesos de PSNRL se suben a **IPFS**.
